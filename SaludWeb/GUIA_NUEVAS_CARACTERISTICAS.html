📖 Guía de Nuevas Características - SaludWEB Pro v3.0

Esta guía documenta todas las nuevas características agregadas a la aplicación MRx Digital. Nada del proyecto original fue eliminado.

💜1. Nueva Sección: Mis Rx

NUEVA Centro de Control Unificado

Acceso centralizado a todas las prestaciones relacionadas con prescripciones y servicios de salud.

mis_rx.php

Subsecciones incluidas:

Función Archivo Descripción
📄 Prescripciones lista_prescripciones.php Ver y gestionar recetas electrónicas
🔔 Notificaciones notificaciones.php Revisar avisos y recordatorios del sistema
🏥 Prestaciones prestaciones.php Consultar servicios disponibles en cobertura
🏪 Buscador de Farmacias buscador_farmacias.php Localizar farmacias cercanas y afiliadas

NUEVA mis_rx.php

Centro de control con acceso rápido a:

  • Panel de navegación intuitivo con 4 opciones principales
  • Sección de contacto con iconos de WhatsApp y Gmail
  • Información de utilidad y estado del sistema
  • Links de regreso a inicio
  • Diseño responsivo para móvil y desktop

NUEVA notificaciones.php

Gestor de notificaciones del usuario con:

  • Filtros por tipo: Todas, Importantes, Recordatorios, Sistema
  • Listado de notificaciones con timestamps
  • Código de colores para diferentes tipos
  • Soporte para notificaciones importantes, advertencias y exitosas

NUEVA prestaciones.php

Catálogo de prestaciones disponibles con:

  • Grid responsive de prestaciones
  • Búsqueda en tiempo real
  • Filtros por categoría: Médicos, Estudios, Odontología, Farmacia
  • Badges de estado: Activa, Limitada
  • Botones para ver detalles de cada prestación

NUEVA buscador_farmacias.php

Herramienta de búsqueda de farmacias con:

  • Búsqueda por zona/localidad
  • Filtro por horario: Todas, Abiertas ahora, 24 Horas
  • Listado de farmacias con información completa
  • Distancia desde ubicación del usuario
  • Botones para ver en mapa y llamar
  • Información de cobertura de planes

NUEVA preguntas_frecuentes.php

Centro de ayuda con preguntas frecuentes:

  • Acordeón interactivo expandible/contraíble
  • Búsqueda en tiempo real de preguntas y respuestas
  • 8 preguntas comunes pre-cargadas
  • Respuestas detalladas y claras
  • Accesible desde múltiples puntos de la aplicación

NUEVA cuenta.php

Página de gestión de perfil del usuario con:

  • Perfil de usuario con avatar y datos personales
  • Formularios de edición de información
  • Gestión de seguridad: cambio de contraseña
  • Autenticación de dos factores (2FA)
  • Zona de peligro para eliminar cuenta

⚙️2. Menú de Ajustes Completo

ACTUALIZADO configuracion.php

Transformado de página de configuración técnica a centro de control de usuario con:

  • 🏠 Home - Enlace a dashboard principal
  • 📄 Prescripciones - Acceso a recetas
  • 🏥 Prestaciones - Consulta de servicios
  • 🔔 Notificaciones - Gestión de avisos
  • ⚙️ Ajustes - Centro de configuración (actual)
  • 👤 Cuenta - Perfil del usuario
  • ❓ Preguntas Frecuentes - Centro de ayuda
  • 🔒 Cerrar Sesión - Logout del sistema

Secciones en Ajustes:

  • Notificaciones - Preferencias de avisos
  • Privacidad y Seguridad - Protección de datos
  • Contacto y Soporte - WhatsApp y Email
  • Centro de Ayuda - Documentación
  • Mis Datos - Descargar o eliminar datos
  • Información del Sistema - Detalles técnicos
